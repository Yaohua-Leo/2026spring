# 抽象代数 III 笔记：新建章节操作手册

本目录已经采用“两层拆分”：

- `Abstractalgebra.tex` 是唯一主文件，保留导言区、封面、目录和章级 `\include`。
- `chapterN.tex` 是章文件，只写 `\chapter{...}` 和若干节级 `\input`。
- `chapterN/NN-section-slug.tex` 是节文件，从 `\section{...}` 开始写正文。
- `homework.tex` 和 `homework/` 用同样方式管理作业章节。

## 1. 新建一讲 Lecture

假设要新增 `Lecture 9`。

1. 在 `notes` 目录下新建章文件：

   ```tex
   % chapter9.tex
   \chapter{Lecture 9}

   \input{chapter9/01-first-topic}
   ```

2. 新建同名目录：

   ```text
   chapter9/
   ```

3. 在目录里新建第一个节文件：

   ```tex
   % chapter9/01-first-topic.tex
   \section{First Topic}

   Your notes start here.
   ```

4. 在 `Abstractalgebra.tex` 的结构区加入新章，通常放在 `homework` 前面：

   ```tex
   \include{chapter8}
   \include{chapter9}
   \include{homework}
   ```

注意：`\include{chapter9}` 不写 `.tex` 后缀。

## 2. 给已有 Lecture 新增一节

假设要给 `Lecture 8` 增加第 6 节。

1. 新建节文件：

   ```tex
   % chapter8/06-new-topic.tex
   \section{New Topic}

   Your notes start here.
   ```

2. 在 `chapter8.tex` 末尾加入：

   ```tex
   \input{chapter8/06-new-topic}
   ```

注意：节文件名建议使用 `两位编号-英文小写短横线`，例如：

```text
01-basic-definitions.tex
02-main-theorem.tex
03-examples-and-remarks.tex
```

节标题可以正常使用 TeX 内容；文件名尽量保持 ASCII、无空格、无中文，方便编译和跨平台同步。

## 3. 新增 Homework Week

假设要新增 `Homework Week 9`。

1. 新建文件：

   ```tex
   % homework/09-homework-week-9.tex
   \section{Homework Week 9}

   \begin{exercise}
       Problem statement.
   \end{exercise}

   \begin{proof}
       Solution.
   \end{proof}
   ```

2. 在 `homework.tex` 末尾加入：

   ```tex
   \input{homework/09-homework-week-9}
   ```

## 4. 编译检查

在 `notes` 目录下运行：

```powershell
latexmk -xelatex -interaction=nonstopmode -halt-on-error Abstractalgebra.tex
```

成功时会更新：

- `Abstractalgebra.pdf`
- `Abstractalgebra.aux`
- 各章的 `chapterN.aux`
- 其他 LaTeX 辅助文件

本仓库已经忽略大多数辅助文件；`Abstractalgebra.pdf` 是跟踪文件，编译后可能出现在 Git diff 里，这是正常的。

## 5. 常见错误

- 主文件只放章级结构，不把正文写回 `Abstractalgebra.tex`。
- 章文件只放 `\chapter` 和 `\input`，不要复制导言区、宏包或 `\begin{document}`。
- 节文件从 `\section{...}` 开始，不写 `\chapter`。
- `\include{...}` 和 `\input{...}` 都不要写 `.tex` 后缀。
- 新建 Lecture 后，别忘了在 `Abstractalgebra.tex` 中加入对应 `\include`。
- 新建节文件后，别忘了在对应 `chapterN.tex` 或 `homework.tex` 中加入对应 `\input`。
