# 2026 Spring 学习记录

这个仓库用于保存 2026 年春季学期的课程笔记、作业、参考资料和阶段性整理稿。它的目标是成为一个可回看、可同步的单学期学习档案，而不是临时 OCR、编译缓存或 agent 运行状态的堆放处。

## 目录导览

- `课表.md`：本学期课程时间表。
- `抽象代数III/`：抽象代数 III 笔记与作业。`notes/` 采用主文件、章节文件、节文件的两层拆分结构。
- `aaa-quiver/`：应用抽象代数、quiver representation 相关笔记、作业、期中材料和参考资料。
- `组合数学II/`：组合数学 II 笔记、作业和参考资料。
- `李理论/`：Lie theory 笔记和参考文献。
- `Jordan algebra/`：Jordan algebra / topics in algebra 相关笔记、期中材料和参考资料。
- `schur-weyl/`：Schur-Weyl 相关草稿、参考文献和整理稿。
- `博资考-群论/`、`讨论班(Lie algebra)/`、`范畴论复习/`、`置换群/`、`cohomology/`：专题复习、讨论班或补充阅读材料。
- `academic_english/`、`Writing for publication/`：学术英语与写作课程材料。
- `template.tex`、`template.pdf`、`latex-split-template/`：LaTeX 模板和拆分笔记模板。

## 目录约定

课程或专题目录优先使用这些子目录：

- `note/`：正式笔记或主讲义。
- `homework/`：作业题、解答或提交稿。
- `reference/`：教材、论文、讲义等参考资料。
- `midterm/`：期中相关题目、解答或整理稿。

根目录只保留总览、课表和通用模板。临时 OCR 文本、改写碎片、agent 状态、编译缓存和一次性实验文件不作为学习内容归档。

## 跟踪规则

- 跟踪 `.tex`、重要 `.md`、课程资料和最终阅读用 `.pdf`。
- 不跟踪 LaTeX 辅助文件，例如 `.aux`、`.log`、`.out`、`.toc`、`.synctex.gz`、`.bbl`、`.blg`。
- 不跟踪 agent/runtime 状态、临时 OCR 管线、`tmp/`、`Untitled` 和改写中间产物。
- `会议手册/` 和 `海报/` 作为本地项目资产保留在工作区，但默认不纳入本学习记录仓库。
